A single one-line 1-star review from a houseplant about the human who
owns it, written by `main.py` to `/output/entry.txt`.

The fern's grievance: bought for a "low-maintenance" label, watered
like a goldfish, parked by a window that gets eleven minutes of sun a
day. It is a fern, not a timeshare.
